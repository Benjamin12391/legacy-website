World Bank Country API

Länder-Kurzinfo

Gib einen zwei- oder dreistelligen ISO-Ländercode ein, zum Beispiel AT, DEU oder BRA.

Der Code wird direkt in die URL für den API-Aufruf übernommen.

Noch keine Suche gestartet. Gib einen Ländercode ein und lade die Informationen.
