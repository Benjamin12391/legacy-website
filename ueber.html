Dokumentation

Über die Länder-Kurzinfo

Diese Website ruft Daten der World-Bank-Country-API ab und stellt ausgewählte Profildaten eines Landes dar.

Verwendete API

Die Anwendung verwendet die Dokumentation der World Bank Country API.

Beispiel-Endpunkt: https://api.worldbank.org/v2/country/AT?format=json

Die API-Antwort ist ein Array: data[0] enthält Metadaten, das Länderobjekt liegt unter data[1][0].

Bedienung

  1. Auf Ländersuche einen ISO-Code mit zwei oder drei Buchstaben eingeben.
  2. Optional einen zweiten Code für einen Vergleich angeben.
  3. „Informationen laden“ wählen.
